# Mini Jira – Employee / Project / Task Tracker

A full-stack Mini Jira–like application to manage employees, projects, tasks, meetings, and reminders with role-based authentication.

## Features
- Admin & Employee login
- Manage Employees
- Manage Projects
- Assign & track Tasks
- Meeting Scheduler
- Reminders
- Role-based access (Admin / Employee)
- JWT Authentication

## Tech Stack
Frontend: React  
Backend: Node.js, Express  
Database: MongoDB  
Auth: JWT  

## Setup (Run Locally)

### Backend
cd todo-backend
npm install

Create `.env`:
MONGO_URI=your_mongodb_uri  
JWT_SECRET=your_secret  
PORT=5000  

npm run dev

### Frontend
cd todo-frontend
npm install
npm start
